# Bruno Ghiggi — página rastreável

1. Crie um repositório público chamado `fotos`.
2. Envie `index.html`, `bruno.jpg` e as pastas `fotto`, `foco` e `whatsapp`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. URL principal: `https://SEU-USUARIO.github.io/fotos/`

Links rastreáveis: `/`, `/fotto/`, `/foco/`, `/whatsapp/`.

Os logos Fotto e Foco Radical usados na página são referências aos logos oficiais das marcas. A Fotto publica seus materiais oficiais e exige que seus logos não sejam modificados.
